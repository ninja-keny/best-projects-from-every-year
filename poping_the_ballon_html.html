Balloon Pop Game

This is a simple balloon pop game I made in 2023 using Scratch. When you click the game link, it will take you straight into the game. Press the orange ball to view the instructions, then start playing. One issue is that there is no way to reset your score back to 0. Despite that, this was the best game I made in 2023, in my opinion. The game also helped me learn about event-driven programming. If I had to rate the difficulty of making it, I would give it a 4/10. Although I added a lot of features, it was built in Scratch, which makes development much easier. If you would like to try the game, click here. As an extra challenge, try to reach Level 2 to win the game!
