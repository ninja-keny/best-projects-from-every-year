pyturtle+ project

This is my PyTurtle+ project, which I started in 2026 using Python. I created it because I wanted to make something that was as easy to use as Scratch while still being as powerful and flexible as Python. The goal of PyTurtle+ is to help beginners learn text-based programming without being overwhelmed by complicated syntax. The project uses Python's Turtle library to display graphics and introduces important programming concepts such as functions, variables, loops, and commands in a much simpler way. In fact, the image/logo shown on the left was created using PyTurtle+ itself. Currently, the language contains more than 15 custom commands, each with its own unique purpose. Commands such as "forward", "backward", "left", and "right" allow users to create graphics quickly, while more advanced features allow the use of variables, functions, loops, and mathematical operations. This project was inspired by my own experience learning Python. Although Python is often considered beginner-friendly, I found the syntax confusing when I first started and often felt overwhelmed trying to learn everything at once. PyTurtle+ aims to reduce that learning curve by providing simple commands while still teaching the fundamentals of programming. The project is still in development and there are currently ways to break it, which is why I continue to update it and look for vulnerabilities and bugs. Because of this, some features are unfinished and may change in future versions. When development is complete, I plan to add support for custom user-defined functions and additional built-in features. My long-term goal is to create a beginner-friendly tool that can be used for learning programming, teaching students, and even developing simple games. I want it to remain as simple as possible while becoming powerful enough to be a genuine alternative for educational graphics programming. If you would like to try the project, click here.
