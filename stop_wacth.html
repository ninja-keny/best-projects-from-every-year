stop wacth

This is my stopwatch project that I made in 2024. It was created in Python using the Turtle library to draw the interface and the Time library to create the timer. The stopwatch can be started, stopped, and reset, and I also designed my own functions to organise the code. This project taught me how to create a toggle system and gave me some experience with building simple user interfaces through the design of the buttons and boxes. It also helped me improve my understanding of functions and time-based programming. If I had to rate the difficulty of this project, I would give it a 4/10. The coding itself was not too difficult, but designing the controls and making the timer work correctly was a good challenge. I have a challenge for you: try to stop the timer exactly at 10 seconds.
