microbit phone project

This is a Micro:bit project that I made in 2024. It uses the radio feature to send letters between two devices. The project can spell words such as "hello", which I demonstrate in the video, and it can also send full sentences. After the letter Z, the Micro:bit displays a blank screen with no LEDs lit, which represents a space between words. I like this project because it is useful in many different ways, and the only real limits are your spelling and creativity. For example, you could create your own encryption method or use it to communicate with a friend who does not have a phone, since a Micro:bit is much cheaper. This project taught me how the Micro:bit radio works, as well as the basics of channels and frequency. If I had to rate the difficulty of building it, I would give it a 5/10. The hardest part was understanding how radio communication works, while most of the programming itself was built using simple if statements. If you would like to try the project yourself, click here. Try it with a friend and see if you can send messages between your Micro:bits!
